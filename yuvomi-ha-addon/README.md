# Yuvomi Family Planner

Home Assistant add-on for [Yuvomi](https://github.com/ulsklyc/yuvomi), a self-hosted family planner (tasks, calendar, budget, meals, shopping, health).

- Wraps the unmodified upstream image, `amd64` and `aarch64`
- Secrets and database encryption key are generated on first start
- Web interface on port 3000

See [DOCS.md](DOCS.md).
